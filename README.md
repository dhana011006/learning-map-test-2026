# Learning Dependency Search Engine

## About the Project
A C++ based intelligent search engine that helps
users understand learning dependencies between concepts.

## Features
- Search for concepts
- Find prerequisite concepts
- Discover subsequent topics
- Generate learning paths using BFS
- Graph-based learning dependency mapping

## Data Structures and Algorithms
- Directed Graph
- Adjacency List
- BFS
- DFS
- Queue
- Hash Map
- Vector

## Technologies
- C++
- STL
- CSV Dataset

## How to Run

Compile:
g++ main.cpp -o main

Run:
./main
